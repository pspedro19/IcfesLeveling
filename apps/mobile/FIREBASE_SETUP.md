# Firebase Authentication Setup Guide

This document explains how to configure Firebase for Google and Apple Sign-In.

## Prerequisites

- Firebase CLI installed: `npm install -g firebase-tools`
- FlutterFire CLI installed: `dart pub global activate flutterfire_cli`

---

## Step 1: Create Firebase Project

1. Go to [Firebase Console](https://console.firebase.google.com/)
2. Click "Add project"
3. Name it: `icfes-leveling`
4. Enable Google Analytics (optional)
5. Create project

---

## Step 2: Add Apps to Firebase

### Android App
1. In Firebase Console, click "Add app" → Android
2. Package name: `com.icfesleveling.mobile`
3. App nickname: `ICFES Leveling Android`
4. Download `google-services.json`
5. Place it in: `apps/mobile/android/app/google-services.json`

### iOS App
1. In Firebase Console, click "Add app" → iOS
2. Bundle ID: `com.icfesleveling.mobile`
3. App nickname: `ICFES Leveling iOS`
4. Download `GoogleService-Info.plist`
5. Place it in: `apps/mobile/ios/Runner/GoogleService-Info.plist`

---

## Step 3: Enable Authentication Methods

In Firebase Console → Authentication → Sign-in method:

### Google Sign-In
1. Click "Google"
2. Enable it
3. Set support email
4. Save

### Apple Sign-In
1. Click "Apple"
2. Enable it
3. You'll need:
   - Apple Developer Account
   - Service ID configured
   - Private key from Apple

---

## Step 4: Configure FlutterFire

Run from `apps/mobile/`:

```bash
flutterfire configure --project=icfes-leveling
```

This will:
- Generate `lib/firebase_options.dart`
- Update native configurations automatically

---

## Step 5: Initialize Firebase in App

Update `main.dart`:

```dart
import 'package:firebase_core/firebase_core.dart';
import 'firebase_options.dart';

void main() async {
  WidgetsFlutterBinding.ensureInitialized();

  await Firebase.initializeApp(
    options: DefaultFirebaseOptions.currentPlatform,
  );

  runApp(const MyApp());
}
```

---

## Step 6: Android-Specific Configuration

### Add SHA-1 fingerprint (for Google Sign-In)

```bash
cd android
./gradlew signingReport
```

Copy the SHA-1 and add it to Firebase Console → Project Settings → Your apps → Android → Add fingerprint

### Update `android/build.gradle`

```gradle
buildscript {
    dependencies {
        classpath 'com.google.gms:google-services:4.4.0'
    }
}
```

### Update `android/app/build.gradle`

```gradle
apply plugin: 'com.google.gms.google-services'

android {
    defaultConfig {
        minSdkVersion 21  // Required for Firebase
    }
}
```

---

## Step 7: iOS-Specific Configuration

### Update `ios/Runner/Info.plist`

Add URL schemes for Google Sign-In:

```xml
<key>CFBundleURLTypes</key>
<array>
    <dict>
        <key>CFBundleTypeRole</key>
        <string>Editor</string>
        <key>CFBundleURLSchemes</key>
        <array>
            <!-- Get this from GoogleService-Info.plist REVERSED_CLIENT_ID -->
            <string>com.googleusercontent.apps.YOUR_CLIENT_ID</string>
        </array>
    </dict>
</array>
```

### For Apple Sign-In

1. In Xcode, enable "Sign in with Apple" capability
2. In Apple Developer Portal:
   - Create App ID with Sign in with Apple
   - Create Service ID
   - Generate private key

---

## Step 8: Run the App

```bash
cd apps/mobile
flutter pub get
flutter run
```

## Troubleshooting

### "Google Sign-In failed"
- Verify SHA-1 fingerprint is added to Firebase
- Check `google-services.json` is in correct location
- Ensure package name matches exactly

### "Apple Sign-In not available"
- Only works on real iOS devices (not simulator for testing)
- Must have Apple Developer Program membership
- Bundle ID must match App ID in Apple Developer Portal

### "Firebase not initialized"
- Ensure `Firebase.initializeApp()` is called before `runApp()`
- Check that `firebase_options.dart` was generated

## Security Notes

- Never commit `google-services.json` or `GoogleService-Info.plist` to public repos
- Add them to `.gitignore` if repo is public
- Use environment-specific Firebase projects for dev/staging/prod
